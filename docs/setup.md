# Adding a device

1. Go to **HA Settings → Devices & Services**.
2. Click **Add Integration**.
3. Search for **Zyxel**.
4. Select the **Zyxel** integration.
5. In **Host**, type your hostname IP, usually something like
   `https://192.168.1.1` (⚠️ enter the full URL scheme with `https://`).
6. Type your admin username and password.
7. Click **Submit**.

!!! note "If connection fails"

    Try with `http://` instead of `https://`.
